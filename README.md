# Himadree Chowdhury — React Portfolio

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown by Vite.

## Customize before submission

Edit `src/main.jsx`:
- Replace the email address.
- Add your GitHub and LinkedIn links.
- Add/replace project details.
- Add your real education details.

For a profile photo, replace the `HC` placeholder in the hero section with an image.

## Build for deployment

```bash
npm run build
```

The production files will be generated in `dist/`.
